## Project Sought: DevBits

**Social infrastructure for builders shipping in public.**

DevBits is my capstone project: a social app for developers to share real progress on what they're building, instead of polished highlight-reel content.

- **Streams** = projects
- **Bytes** = updates on those projects
- **Bits** = comments

People post milestones, blockers, and lessons learned as they happen.

**Stack**

![Go](https://img.shields.io/badge/Go-1.24-00ADD8?style=flat-square&logo=go&logoColor=white)
![Gin](https://img.shields.io/badge/Gin-API-009688?style=flat-square&logo=gin&logoColor=white)
![React Native](https://img.shields.io/badge/React_Native-Expo-61DAFB?style=flat-square&logo=react&logoColor=black)
![TypeScript](https://img.shields.io/badge/TypeScript-3178C6?style=flat-square&logo=typescript&logoColor=white)
![PostgreSQL](https://img.shields.io/badge/PostgreSQL-Prod-4169E1?style=flat-square&logo=postgresql&logoColor=white)
![AWS](https://img.shields.io/badge/AWS-EC2%2FRDS-FF9900?style=flat-square&logo=amazonaws&logoColor=white)

I built the backend in Go with Gin, using JWT auth and PostgreSQL in production (SQLite for tests). The mobile app is React Native with Expo Router, and I deployed the backend on AWS. It includes a follow system, a discovery/explore feed, direct messaging, and full builder profiles.

DevBits pulls together everything I've been working on: full-stack development from my personal projects, and the server management and deployment experience I've built at Saratech, now applied to shipping a real production app end to end.
